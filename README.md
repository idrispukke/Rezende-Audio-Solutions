# Rezende Audio Solutions

Sistema de gestão e site institucional para a Rezende Audio Solutions,
empresa de engenharia de áudio.

## Stack

- **Frontend:** React + TypeScript
- **Backend:** Python
- **Banco de dados:** Supabase

## Estrutura do repositório

```
.
├── frontend/   # Aplicação React + TypeScript
├── backend/    # API em Python
├── supabase/   # Migrations e seed do banco de dados
└── .github/    # Workflows de CI/CD
```

## Como rodar

_Preencher com instruções de setup de frontend, backend e Supabase._
