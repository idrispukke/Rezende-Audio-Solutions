# Rezende Audio Solutions

Plataforma web profissional desenvolvida para apresentação comercial e gestão operacional de serviços técnicos de áudio, eventos corporativos e produções audiovisuais.

O sistema atua como o principal canal de captação de clientes da empresa, além de fornecer uma infraestrutura administrativa completa (Mini-ERP) para organizar o fluxo de trabalho nos bastidores.

## 🌐 Site Comercial (Captação)
* **Portfólio Dinâmico:** Apresentação da empresa, serviços especializados e galeria de eventos e produções realizadas.
* **Orçamentos Inteligentes:** Formulário detalhado para captação de leads, mapeando informações cruciais do evento (data, local, público, necessidades técnicas).
* **Atendimento Integrado:** Redirecionamento rápido para WhatsApp e integração com Instagram.

## 📊 Dashboard Administrativo (Operação)
* **Gestão de Eventos:** Acompanhamento de status de cada projeto (Orçamento → Confirmado → Em Execução → Finalizado).
* **Controle de Equipamentos:** Monitoramento de disponibilidade de estoque, reservas vinculadas a eventos e painel de manutenção.
* **Base de Clientes:** Histórico centralizado de contatos, empresas parceiras e serviços já prestados.
* **Visão Financeira:** Acompanhamento de propostas aprovadas, custos operacionais (equipe e logística) e lucratividade.

## 🛠️ Tecnologias Utilizadas
* **Frontend:** React + TypeScript
* **Backend:** Python
* **Banco de Dados & Auth:** Supabase (PostgreSQL)
* **Infraestrutura:** Docker e GitHub Actions (CI/CD)
